# GitRadar 📡

GitRadar — это автоматизированная система для мониторинга GitHub, поиска инструментов для разработки AI-агентов и формирования структурированной базы скиллов с доставкой через Telegram.

## 🚀 Основные возможности
- **Автоматический сбор**: Поиск по ключевым словам и трендам GitHub.
- **Умный анализ**: Определение категории, расчет релевантности (Score 0-5), анализ зависимостей.
- **Telegram-интерфейс**: Поиск инструментов, просмотр новинок и топ-списков.
- **Дайджесты**: Регулярные подборки лучших инструментов в Telegram-канал.

## 🛠 Технологический стек
- **Язык**: Python 3.11+
- **БД**: PostgreSQL
- **Бот**: aiogram 3.x
- **API**: GitHub REST API
- **Оркестрация**: APScheduler, Docker Compose

## ⚙️ Подготовка и настройка

### 1. Получение GitHub Token
Для работы сборщика данных необходим доступ к GitHub API:
1. Зайдите в свой профиль GitHub $\rightarrow$ **Settings** $\rightarrow$ **Developer settings**.
2. Выберите **Personal access tokens** $\rightarrow$ **Tokens (classic)**.
3. Нажмите **Generate new token (classic)**.
4. Укажите название (например, `GitRadar-Bot`) и выберите необходимые scope (достаточно `public_repo` или общего доступа к публичным данным).
5. Скопируйте полученный токен — он понадобится для файла `.env`.

### 2. Настройка базы данных PostgreSQL
#### Вариант А: Через Docker (Рекомендуется)
База данных будет развернута автоматически с помощью `docker-compose`. Вам не нужно ничего устанавливать локально.

#### Вариант Б: Локальная установка
1. Установите PostgreSQL с [официального сайта](https://www.postgresql.org/download/).
2. Создайте базу данных:
   ```bash
   psql -U postgres
   CREATE DATABASE gitradar;
   ```
3. Убедитесь, что пользователь и пароль совпадают с теми, что вы укажете в `.env`.

### 3. Настройка окружения
1. Скопируйте шаблон файла с переменными:
   ```bash
   cp .env.example .env
   ```
2. Откройте `.env` и заполните ваши данные:
   - `GITHUB_TOKEN`: ваш токен из шага 1.
   - `TELEGRAM_BOT_TOKEN`: токен от @BotFather.
   - `DATABASE_URL`: строка подключения к БД. 
     - Для Docker: `postgresql+asyncpg://user:password@db:5432/gitradar`
     - Для локальной БД: `postgresql+asyncpg://user:password@localhost:5432/gitradar`

## 📦 Запуск приложения

### Способ 1: Docker Compose (Самый быстрый)
Этот метод развернет и базу данных, и приложение в изолированных контейнерах.

```bash
# Сборка и запуск в фоновом режиме
docker-compose up --build -d
```

### Способ 2: Локальный запуск (Для разработки)
1. **Установите Poetry**:
   ```bash
   pip install poetry
   ```
2. **Установите зависимости**:
   ```bash
   poetry install
   ```
3. **Активируйте окружение и запустите бота**:
   ```bash
   poetry shell
   python -m src.main
   ```

## ✅ Проверка работы

### 1. Проверка логов
Если вы используете Docker, проверьте, что приложение запустилось без ошибок:
```bash
docker logs -f gitradar_app
```
Вы должны увидеть сообщения об успешном подключении к БД и запуск бота.

### 2. Тестирование в Telegram
Найдите своего бота в Telegram и отправьте следующие команды:
- `/start` — Бот должен ответить приветственным сообщением.
- `/search ai agent` — Бот должен выполнить поиск по базе и вернуть результаты.
- `/new` — Проверка последних добавленных инструментов.

### 3. Проверка БД (опционально)
Вы можете подключиться к контейнеру с БД, чтобы проверить наличие данных:
```bash
docker exec -it gitradar_db psql -U user -d gitradar
# Выполните запрос: SELECT * FROM tools LIMIT 5;
```

## 🛠 Команды бота
- `/start` — запуск и помощь.
- `/search <запрос>` — поиск по базе.
- `/new` — последние добавленные инструменты.
- `/top` — топ по звездам.
- `/admin_cat <url> <category>` — (Админ) смена категории.
- `/admin_del <url>` — (Админ) удаление записи.
